## OC2 — Is provisional stopping sufficient?

“Sufficient” is scoped. Not sufficient for metaphysical finality. The load under test:

$$
\boxed{
\text{operational coherence + usable conclusions + reopenable later without contradiction}
}
$$

$R$ is not a premise. The question is whether *provisionality* can carry that load, not whether universal revisability is true.

### Requirements that might demand more

**Community coordination / consensus.**  
A shared stopping point lets work proceed. Science already treats consensus as revisable. Coordination needs $\mathrm{Stop}(I)$ recorded, not $\mathrm{Final}(\text{inquiry})$.

**Pedagogy / communication.**  
Teaching presents current results as usable. That is transmission of a stopping point. Reopening the textbook is ordinary, not a contradiction.

**Institutional verdicts.**  
A case can be closed for action (res judicata, a shipped paper, a committed proof in $S$). That is $\mathrm{Final}(I)$ relative to an institution or frame. Overruling and theory-change remain available. Frame-relative finality $\neq$ terminal closure of inquiry.

**Theoremhood in a specified formal system $S$.**  
Strongest converse candidate. Given $S$, a proof is not “we stopped looking.” It is: no counterexample exists *in $S$*. That is more than provisional search-termination.

It is still not $\mathrm{Final}(\text{inquiry})$. $S$ itself can be replaced. What is closed is $I$ given $S$, not inquiry as such. Conflating those two is the same stipulation OC1 already flagged: define the task as last-word-in-$S$, get closure-in-$S$.

**Paralysis / endless reopening.**  
If every claim stays *actively* open, nothing can be used. That is an argument *for* provisional stopping, not against its sufficiency. The work is done by distinguishing in-principle revisability from infinite active reassessment. OC2 does not install that distinction as $R$.

**Identity of the method over time.**  
A method can persist as a lineage of provisionally stopped inquiries. A closed essence of the method is not required for the lineage to be trackable.

**Self-audit.**  
The enclosure stall is $\mathrm{Stop}$ on a particular self-audit without $\mathrm{Final}(A)$. Reopening that audit is what *this* file is. No contradiction has been produced by that pair.

### Where provisional stopping is not sufficient

- Any task stipulated as “produce the last word.”
- Any result whose identity is “settled-in-$S$” if $S$ is silently identified with inquiry itself.

Both are task- or frame-stipulations, not independent requirements *for inquiry*.
