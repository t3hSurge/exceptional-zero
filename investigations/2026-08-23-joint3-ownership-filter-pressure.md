# Joint 3 → History-Mediated Interest: Ownership-Filter Pressure

**Status:** Tested; ownership-filter question narrowed, not closed universally  
**Scope:** Whether causal ancestry can be restricted to a subject/system-specific reaching history without importing diachronic identity or an arbitrary representation boundary  
**No `G*_2`. No `Σ`. No process/material preference.**

---

## 1. Question

The history-mediated bridge remains live only in the form

\[
J3+H_R+L\rightarrow I,
\]

where `H_R` must be more specific than unrestricted causal ancestry. For a present state `s_t`, let

\[
A(s_t)=\{s_i:s_i\leadsto s_t\}.
\]

The required history would be a restricted subset

\[
R_t^*\subseteq A(s_t)
\]

containing the reaching events that count as this system's reaching history.

The present pressure is whether `R_t^*` can be specified without presupposing identity or reproducing the unresolved `G*` membership problem.

---

## 2. Identity-defined ownership

The obvious rule is:

> retain events belonging to the same self.

If “same self” means the diachronic identity relation under investigation, this is circular. The proposed history is selected by the very fact it is supposed to help explain.

\[
\boxed{\text{identity-defined ownership is circular}}
\]

This is the same Construction-B failure already diagnosed elsewhere, now appearing inside the history object.

---

## 3. Privileged physical/system boundary

An identity-free alternative is to retain events inside an independently specified physical or system boundary.

This is logically possible in form. But the boundary must satisfy the same requirements imposed on a selective `G*`:

\[
\boxed{
\text{independently specified}
\land
\text{representation-invariant}
\land
\text{refinement/coarse-graining stable}
\land
\text{non-identity-selective}
}
\]

If such a boundary is simply the boundary surrounding the thing whose identity is being tracked, identity has returned under a new name. If it depends on a privileged factorization of the physical description, the `G*_1` membership problem has returned.

Therefore this repair remains **live only conditionally**; no surviving boundary has been exhibited here.

---

## 4. Causal-role ownership

Another rule is to retain events occupying a specified causal role relative to `s_t`.

This avoids explicit identity language, but in the de-loaded replacement/recombination construction both process continuity and material provenance can occupy legitimate causal roles in the same ancestry:

\[
P\subseteq A(s_t),\qquad M\subseteq A(s_t).
\]

Causal-role ownership therefore does not by itself select `P` over `M` or `M` over `P`.

Any additional weighting that privileges one family requires another rule. If that rule is justified by what the subject “really is,” identity-selection has re-entered; if it is imported from task, convention, or another external criterion, that criterion is doing the selecting rather than bare Joint 3/history.

\[
\boxed{\text{causal-role ownership does not resolve mixed }P/M\text{ ancestry}}
\]

---

## 5. All ancestral reaching

The simplest identity-free rule is to keep every reaching event in the causal ancestry:

\[
R_t^*=R_t.
\]

That avoids a membership boundary, but the resulting history can include the subject's own reaching, other agents' reaching, environmental interventions, side effects, and unrelated ancestral events.

It is therefore too broad to determine a subject-specific propositional interest without an additional filter.

\[
\boxed{\text{unrestricted ancestry is a causal bucket, not a determinate subject-history}}
\]

---

## 6. The de-loaded `P/M` pressure

Even if an independently bounded ownership rule were eventually found, ownership alone would not solve the original continuity disagreement.

The resulting history may still contain:

\[
P\subseteq R_t^*,\qquad M\subseteq R_t^*.
\]

Thus the filter could establish at most:

\[
\text{“these events belong to the bounded system/history”},
\]

not:

\[
P\succ M
\quad\text{or}\quad
M\succ P.
\]

A successful ownership filter would therefore earn a determinate history object, not an identity selector.

---

## 7. Exact result

| Ownership rule | Result |
|---|---|
| Same-self membership | **Circular** |
| Privileged physical/system boundary | **Conditionally live; independently bounded survivor unshown** |
| Causal-role filter | **Does not resolve mixed `P/M` ancestry** |
| All causal ancestry | **Too broad to determine subject-specific interest** |

The strongest earned conclusion is:

\[
\boxed{
\text{An identity-free history object is possible in form, but an identity-free ownership filter has not been shown.}
}
\]

This does **not** refute all history-mediated accounts. It narrows their remaining live form to something requiring an independently justified system boundary (or an equivalent filter) before `L` can be meaningfully constructed.

---

## 8. Status and next pressure

The bridge remains:

\[
J3+H_R+L\rightarrow I
\;?\;
I\rightarrow C_*
\;?\;
C_*\rightarrow\text{identity attribution}.
\]

Each bridge remains independent.

The ownership-filter pressure is now locked as a prerequisite rather than silently assumed. The next legitimate test, if this line continues, is **not** to invent a favorite boundary. It is to ask whether an independently specified system boundary exists at all, under the already-earned representation, refinement, coarse-graining, and anti-circularity requirements.

No `G*_2` is constructed. No `Σ` is introduced. No interest-relative identity claim is promoted. No process/material ranking is established.
