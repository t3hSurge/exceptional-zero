# Review: Diachronic Identity — The C* Battery

**Date:** 2026-08-20  
**Reviewed investigation:** `investigations/2026-08-20-diachron-identity-causal-relation-cstar.md`  
**Status:** Complete for the current round  
**Canonical status affected:** None; UCL remains provisional.

---

## 1. Executive finding

The C* pass sharpens the UCL problem considerably.

The question is no longer whether some causal asymmetry can be found. That was already established by UCL.

The question is whether a **domain-general causal relevance relation** can be selected from the full causal graph without using the identity verdict to decide which causal edges matter.

The current battery does not produce a completed C*.

It does, however, narrow the viable candidates to two:

1. **counterfactual causal relevance**, which is broadly portable but depends on an intervention/background model;
2. **constitutive/organizational causation**, which can filter incidental effects but faces a direct individuation/circularity problem.

Biological/developmental, material, environmental, and social/linguistic restrictions can work locally, but each is either domain-specific or requires additional selection rules.

**C* remains Open. UCL remains a provisional survivor.**

## 2. Important negative result: “causal” is not a sufficient category

The total causal graph is unusably permissive.

Any stage is causally connected to enormous numbers of downstream effects. If every edge counts, `J_cut` fragments persistence into a dense collection of short segments.

So the phrase “causal provenance” is not yet a theory. It hides a necessary second selection:

\[
C \longrightarrow C_*.
\]

The C* question is therefore not optional bookkeeping. It is the core reduction problem.

## 3. Candidate families

### Biological/developmental

This is independently specifiable in organisms and therefore survives anti-circularity locally. But it fails domain portability: it cannot be the general causal criterion for persons, artifacts, processes, or other entities without importing additional machinery.

It therefore supports **local UCL**, not general UCL.

### Material/component

This is cleanly third-person but rejects gradual replacement too aggressively and cannot by itself settle reconstruction from original components.

The failure is instructive because the candidate illustrates the difference between a causal relation and one particular causal substrate. UCL was attractive partly because it did not require material sameness; reverting to material ancestry simply recreates Ship-of-Theseus pressure.

### Environmental

Environmental causal relations are genuinely external and can distinguish an internal counterfeit, but they are wildly overinclusive. Ordinary interaction with walls, records, infrastructure, other people, and downstream artifacts would all enter C* unless another selector says which environmental effects count.

That selector is precisely what remains to be earned.

### Social/linguistic

This family is independently describable but clearly domain-limited. It also has a direct counterfeit problem: social recognition and documentation can themselves be duplicated.

It therefore cannot supply the domain-general C* presently sought.

## 4. The strongest candidate: counterfactual causal relevance

Define a causal edge using a specified intervention model: changing the candidate cause while holding the permitted background fixed changes the candidate effect.

This is substantially stronger than ordinary causal ancestry because it offers an independent criterion for relevance.

The problem is **selection inside the causal model**.

Different intervention/background choices can yield different causal graphs. Redundant causes, preemption, overdetermination, and engineered environments all make “the causally relevant edge” depend on which variables are admitted as manipulable and which are treated as fixed background.

That is not automatically circular. The intervention model could be independently specified.

But then the theory has to show that the reasonable independently specified intervention models converge on the same C*.

That convergence has not been shown.

This is the strongest live route because its vulnerability is a genuine formal choice problem rather than an obvious identity relabeling.

## 5. Constitutive/organizational causation

This candidate tries to count only causal relations participating in maintenance of the entity’s organization.

It has an attractive property: it rejects many irrelevant side-effects while permitting gradual replacement and repair.

But “the organization of the entity” requires an independently specified individuation rule.

If that organization is selected because it tracks the pre-theoretic individual, the candidate is circular. If it is specified independently, multiple organizations may exist within the same physical process, and cloning/fission shows that organization can be multiply instantiated.

So this candidate is genuinely alive but not yet a survivor.

## 6. New formal constraints on C*

The investigation's C1–C8 constraints are useful and should be treated as the minimum admission criteria, not as a proposed solution:

- **C1 Target independence** — no identity-bearing language.
- **C2 Isomorphism invariance** — isomorphic causal structures receive isomorphic C* relations.
- **C3 Non-triviality** — C* is neither automatically everything nor nothing.
- **C4 Junction stability** — C* works coherently with `J_cut`.
- **C5 Redundancy tolerance** — redundant causes do not arbitrarily alter persistence.
- **C6 Side-effect rejection** — generic consequences do not automatically become identity-bearing edges.
- **C7 Counterfeit sensitivity** — causal differences that actually distinguish provenance remain visible.
- **C8 Domain portability** — the relation is not secretly organism-specific, artifact-specific, or person-specific unless explicitly scoped that way.

These constraints materially improve the problem because they let future candidates fail for explicit reasons instead of by intuition.

## 7. Strongest current result

The C* pass has not produced another provisional survivor.

Its contribution is instead a sharper reduction boundary:

> **UCL supplies an external source of asymmetry, but causal asymmetry alone is too permissive. A successful theory still needs an independently specified rule selecting which causal relations are identity-relevant.**

That rule cannot be obtained merely by pointing at the causal history that yields the desired identity verdict.

## 8. Recommended next test

Do not generate another broad causal family yet.

Fix one explicit intervention semantics for the causal graph and test **counterfactual causal relevance** against:

- overdetermination;
- preemption;
- redundant repair;
- fission/cloning;
- reconstruction;
- irrelevant downstream effects;
- an engineered counterfeit with matched intervention structure.

The decisive question is whether the resulting C* is robust under reasonable independently motivated choices of intervention and background variables.

If it is not, the problem is not that counterfactual causation is false; it is that it does not supply the uniqueness required by UCL.

If it is, we will have a serious candidate for the missing third layer.
